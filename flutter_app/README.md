# فانتازي أرينا — تطبيق Flutter

تطبيق عربي (RTL) لإحصاءات فانتازي الدوري الإنجليزي، يجلب البيانات من الواجهة الرسمية:

```
https://fantasy.premierleague.com/api/bootstrap-static/
https://fantasy.premierleague.com/api/fixtures/
https://fantasy.premierleague.com/api/element-summary/{playerId}/
https://fantasy.premierleague.com/api/entry/{entryId}/
```

## ما يحتويه التطبيق

| الشاشة | المحتوى |
| --- | --- |
| الرئيسية | الجولة الحالية، متوسط النقاط، أفضل اللاعبين، الفورمة، صعود/هبوط الأسعار |
| اللاعبون | بحث + فلترة بالمركز + فرز (نقاط، سعر، فورمة، أهداف، xGI، امتلاك) |
| تفاصيل اللاعب | كل الإحصاءات + xG/xA + ICT + تاريخ الجولات + المواسم السابقة |
| فريقي | اكتب رقم المدير (Entry ID) لعرض الترتيب، القيمة، البنك، التشكيلة والكابتن |
| المباريات | جدول الجولات، النتائج وصعوبة المباريات (FDR) |
| الإحصاءات | 12 تصنيفاً: هدافون، صناع، xG، xA، بونص، BPS، تصديات، شباك نظيفة… |

## التشغيل في Klencode IDE

1. أنشئ مشروع **Flutter** جديد داخل التطبيق (New Project → Flutter → اسم الحزمة `fpl_arena`).
2. انسخ محتوى مجلد `lib/` من هذه الحزمة إلى مجلد `lib/` في مشروعك (استبدل `main.dart`).
3. انسخ `pubspec.yaml` (أو أضف `http: ^1.2.0` و`intl: ^0.19.0` إلى Dependencies).
4. اضغط **Get Packages / Pub Get**.
5. شغّل التطبيق (Run) على المحاكي أو جهازك.

> إذا طلب المحرر مجلدات المنصات (`android/`, `ios/`)، شغّل أمرًا واحدًا في الطرفية داخل مجلد المشروع:
>
> ```bash
> flutter create .
> ```
>
> ثم شغّل `flutter pub get` من جديد.

## ملاحظات

- الواجهة الرسمية لا تحتاج مفتاح API، لكن قد ترفض الطلبات الكثيفة؛ التطبيق يخزّن Bootstrap في الذاكرة لتقليل الطلبات.
- الأسعار في الفانتازي تُخزَّن ×10 (مثال: 145 تعني 14.5 مليون) وقد تم تحويلها داخل التطبيق.
- للاتصال بواجهة JSON الخاصة بنسخة الويب (بدل الواجهة الرسمية) عدّل في `lib/core/api.dart`:
  ```dart
  static const String base = 'https://YOUR-APP-DOMAIN/api/fpl';
  ```
  مع تعديل مسارات المدير إذا لزم.
- هذا التطبيق غير تابع رسمياً لـ Fantasy Premier League.
